koESP32-Based Wi-Fi and Bluetooth Home Automation System

Project Overview

This project implements a smart home automation system using an ESP32 microcontroller. It allows users to control four electrical appliances through Wi-Fi, Bluetooth and physical switches.

Key Features

- Control four electrical appliances using an ESP32.
- Wireless control through Bluetooth.
- Remote control using the Blynk mobile application.
- Manual control using physical switches.
- Automatic Wi-Fi reconnection.
- Automatic Blynk reconnection.
- Synchronization of Bluetooth commands with the Blynk application.
- Relay-based appliance switching.

Hardware Components

- ESP32 Development Board
- 4-Channel Relay Module
- Physical Switches
- 5V Power Supply
- Connecting Wires
- Electrical Loads (Lights and Fan)

Software and Tools

- Arduino IDE
- Embedded C/C++
- Blynk IoT Platform
- Wi-Fi Communication
- Bluetooth Communication

Bluetooth Command Configuration

Command| Operation
A| Light 1 ON
a| Light 1 OFF
B| Light 2 ON
b| Light 2 OFF
C| Fan ON
c| Fan OFF
D| Light 3 ON
d| Light 3 OFF

Blynk Virtual Pin Configuration

Virtual Pin| Appliance
V0| Light 1
V1| Light 2
V2| Fan
V3| Light 3

Project Outcome

Developed an ESP32-based home automation system integrating Bluetooth, Wi-Fi, Blynk mobile application control and physical switch operation.
