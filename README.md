ESP32-Based Wi-Fi and Bluetooth Home Automation System

Project Overview

This project focuses on developing a smart home automation system using an ESP32 microcontroller. It allows users to control two lights and one fan through a mobile application using Wi-Fi and Bluetooth, as well as physical switches.

Key Features

- Control two lights and one fan using an ESP32.
- Wireless control through Wi-Fi and Bluetooth.
- Remote operation using the Blynk mobile application.
- Manual control using physical switches.
- Relay-based switching system.
- Independent physical switch operation.

Hardware Components

- ESP32 Development Board
- 3-Channel Relay Module
- Physical Switches
- 5V Power Supply
- Connecting Wires
- Light Loads and Fan

Software and Tools

- Arduino IDE
- Embedded C/C++
- Blynk IoT Platform
- Wi-Fi and Bluetooth Communication

GPIO Configuration

Component| ESP32 GPIO
Light 1 Relay| GPIO 18
Light 2 Relay| GPIO 19
Fan Relay| GPIO 21
Switch 1| GPIO 25
Switch 2| GPIO 26
Switch 3| GPIO 27

Applications

- Smart Home Automation
- Wireless Electrical Appliance Control
- IoT-Based Home Monitoring and Control

Project Outcome

Successfully developed an ESP32-based home automation system integrating wireless mobile control and manual switch operation.
